libdivide ARM SVE contribution

Contributions to the upstream libdivide project adding ARM SVE support for its vector division paths.

I implemented and submitted SVE vector division paths for all widths, with tests, documentation, and Graviton4 benchmarks against the existing NEON implementation.

  • Around 5x faster 16-bit division vs NEON from wider scalable vectors and native lane operations.
  • Around 3x faster 64-bit division vs NEON from SVE native vector multiply-high instructions.

Pull requests

  • PR #158: Added the initial ARM SVE backend for 16/32/64-bit signed and unsigned vector division, wired into CMake, tests, benchmarks, and documentation.
  • PR #159: Optimized the SVE backend and added an optional SVE2 path using predicated merge-adds and SVE2 halving-add instructions where they improved Graviton4 performance.
  • PR #161: Updated the Windows GitHub Actions CI matrix from the deprecated Windows 2019 runner to Windows 2025 and moved the Visual Studio generator to 2022.
  • PR #162: Fixed Windows CI failures by tightening MSVC warning handling, adding MSVC bit-scan helpers, and using a Windows timer path in the division benchmark.
