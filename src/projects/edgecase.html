EdgeCase — hardware-in-the-loop debugger

Multi-agent firmware debugging system built for TreeHacks 2026.

EdgeCase runs local NVIDIA NIM agents against real RP2350 UART evidence, keeping hardware access isolated behind a build, flash, and serial-capture runner.

  • Automates firmware build, flashing, USB serial discovery, and timestamped UART capture.
  • Stores reproducible evidence bundles with firmware artifacts, logs, metrics, and triage output.
  • Streams agent activity, run state, UART output, and validator confidence to a live dashboard.
