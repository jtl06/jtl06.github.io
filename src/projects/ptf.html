PTF — Linux performance lab

C++ profiling puzzles built around measurement, optimization, and correctness.

PTF presents correct but intentionally slow programs, then grades optimized implementations against output checks and repeatable speedup targets.

  • Syscall Storm uses strace to find excessive read calls, targeting at least 100x speedup.
  • Cache Maze uses perf to diagnose poor locality in a 4096 by 4096 image filter, targeting 4x speedup.
  • Branch Lottery measures hardware branch counters and targets a 1.5x speedup without changing output.
